## NestJS 项目搭建完整计划

### 核心交付物
1. **项目初始化**：使用 pnpm 初始化 NestJS 项目，安装所有核心依赖（TypeORM、JWT、Redis、Swagger 等）
2. **配置体系**：tsconfig.json（双引号、分号）、jest 配置、环境变量（.env.dev/test/prod）
3. **Foundation 层**：
   - 统一错误处理（ErrorCodes、BusinessException、HttpExceptionFilter）
   - 统一响应格式（ResponseInterceptor，注意时间戳单位差异）
   - 请求追踪（RequestIdMiddleware、RequestLoggerMiddleware）
   - 常量/枚举/装饰器/守卫/工具函数
4. **Config & Database**：配置加载器、TypeORM DataSource（用于迁移）
5. **Common 集成层**：Logger（Winston）、Redis、Email、SMS、FileStorage 模块
6. **业务模块**：
   - Auth：完整 JWT 认证（注册/登录/刷新/登出）
   - User/Project/Scene/FileManagement：CRUD 骨架
   - Health/Demo：基础模块
7. **应用入口**：main.ts（全局管道/过滤器/拦截器/Swagger）、app.module.ts
8. **Docker**：docker-compose.yml（PostgreSQL + Redis）、Dockerfile
9. **测试**：单元测试（foundation 关键组件）、e2e 测试框架
10. **数据库迁移**：初始 schema 迁移文件

### 关键约束
- Node 版本：当前 v18.20.7（指南要求 >=20.11.0）
- 代码风格：2空格缩进、双引号、分号、尾随逗号
- 时间戳：错误响应用毫秒，成功响应用秒
- DTO：所有字段必须有 Swagger description 和 example
- synchronize：必须关闭，使用迁移管理表结构

### 验证步骤
每个阶段完成后执行：
- `pnpm build`（编译）
- `pnpm test`（单元测试）
- `pnpm test:e2e`（E2E 测试）
- `pnpm lint`（代码检查）
